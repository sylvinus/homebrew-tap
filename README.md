# Sylvinus Tap

## How do I install these formulae?

`brew install sylvinus/tap/<formula>`

Or `brew tap sylvinus/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sylvinus/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
